iThe settled all-time view: on each day, the average D1/D3/D7/D30 across EVERY cohort from the beginning through that day. Pooled (total returners divided by total cohort size), so a 3-person cohort cannot swing it like a 300-person one. A cohort joins a lag's average only once that lag has matured. Reading these charts
  • New Users has history (backfilled from each account's creation date by backfill-firstseen.js), but only for accounts not yet deleted at backfill time.
  • DAU before the recording deploy is a known floor: it counts only account signups (so it equals New Users on those days). Returning visits were never recorded historically; players.lastActive is one overwritten timestamp (see "Players last seen" on Engagement).
  • Retention is n/a (a gap in the line) for a cohort until day D+N has passed, and for any cohort that joined before live activity recording began.
  • Source is Unknown for every account created before acquisition capture shipped.
